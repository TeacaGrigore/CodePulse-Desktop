# CodePulse Desktop

Aplicație desktop ușoară pentru organizarea notițelor de cod, comenzilor frecvente și snippet-urilor de programare.

## Despre aplicație
**CodePulse Desktop** oferă programatorilor un spațiu simplu pentru salvarea rapidă a fragmentelor de cod și gestionarea versiunilor proiectului prin Git și GitHub.

## Funcționalități
- Salvarea și organizarea snippet-urilor de cod
- Căutare rapidă după limbaj sau cuvinte-cheie
- Interfață simplă și intuitivă
- Gestionarea versiunilor cu Git și GitHub
